# Design System Reviewer

Design-system review for repos using **Astryx** (`@astryxdesign/cli` + `@astryxdesign/core`). General bug review is [Cursor Bugbot](../../docs/code-review-ci.md), not this script.

Requires `npm ci` in CI so `npx astryx` resolves. Workflow: [`.github/workflows/astryx-advisory-review.yml`](../../.github/workflows/astryx-advisory-review.yml).

Docs: [`docs/astryx-ci.md`](../../docs/astryx-ci.md) (Design System Reviewer section).
