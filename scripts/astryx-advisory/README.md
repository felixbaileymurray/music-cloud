# Astryx advisory PR review

Design-system review for repos using **Astryx** (`@astryxdesign/cli` + `@astryxdesign/core`). Not portable to non-Astryx projects — use [`scripts/code-review/`](../code-review/) for general review.

Requires `npm ci` in CI so `npx astryx` resolves. Workflow: [`.github/workflows/astryx-advisory-review.yml`](../../.github/workflows/astryx-advisory-review.yml).

Docs: [`docs/astryx-ci.md`](../../docs/astryx-ci.md) (Astryx advisory section).
